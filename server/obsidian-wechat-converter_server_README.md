# 文件夹说明书

## 核心功能

承载可选微信代理服务和运维管理脚本。

## 输入

接收 HTTP 请求、环境变量、微信 API 凭证、部署环境和管理命令。

## 输出

输出代理响应、健康状态、日志和服务启动/管理结果。

## 定位

位于 server/，是可选后端辅助边界；插件主流程必须能在没有该服务时按设置运行。

## 依赖

Node.js HTTP runtime、微信开放平台 API、部署环境变量和代理配置。

## 维护规则

- 每次新增、删除、移动文件或调整目录职责后，必须更新本 README。
- 目录职责影响项目结构、流程、架构或技术栈时，同步更新 docs/basic/ 对应文档。
