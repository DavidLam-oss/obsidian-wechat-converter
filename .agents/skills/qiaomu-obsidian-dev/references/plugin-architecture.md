# 插件类型与通用架构

每个 Obsidian 插件先按主任务分类，再组合专项能力。分类不是目录标签，而是用来确定状态所有者、主要副作用、性能维度和真实验收。一个插件可以跨类型，但必须指出哪个是主路径。

## 类型与首要风险

| 主类型 | 常见形态 | 首要风险 | 最小真实验收 |
| --- | --- | --- | --- |
| 命令/自动化 | 命令面板、菜单、批处理 | 重复执行、目标错误、不可撤销副作用 | 当前文件/多文件、撤销或恢复、重复触发 |
| 编辑器增强 | CM6 装饰、补全、格式化、选区动作 | offset 映射、IME、撤销栈、长文性能 | 输入/删除/选区/撤销、Live Preview、长文 |
| 自定义视图/面板 | dashboard、侧栏、日历、任务板 | 多 leaf、重载恢复、过期状态、宿主布局 | 多窗口/分屏、关闭重开、空/错/加载态 |
| 数据/索引/搜索 | 标签、关系、数据库、全文索引 | 启动扫描、事件风暴、陈旧缓存、重命名删除 | 冷启动、增量更新、rename/delete、规模数据 |
| 导入/导出 | CSV、网页、剪藏、转换、备份 | 数据丢失、路径/编码、重复导入、格式漂移 | 真实文件、冲突、幂等、导出读回 |
| 网络/同步/发布 | API、云服务、跨设备、第三方平台 | 认证、限流、乱序、部分成功、隐私 | 真实账号或受控服务、离线/重试、读回 |
| 媒体/阅读 | PDF、音频、视频、RSS、电子书 | 大资源、定位、播放/渲染生命周期 | 对应格式、长时间/大文件、恢复位置 |
| AI/Agent | provider、工具、MCP/Skill、笔记写回 | 权限、上下文泄漏、并发覆盖、不可核验输出 | 真实模型/工具、审批、取消、结果落地 |

不要因为最近做过 Reader/Seed/Radio，就给新插件默认增加阅读、AI、播放器、频道或跨插件协议。只有产品任务需要时才加载对应专项参考。例外是乔木系列插件：开发前按 [乔木插件家族协议](qiaomu-family.md) 判断是否有可「继续/新建/搜索」或值得问 AI 的内容，有才接入。

## 通用设计五问

1. **用户动作是什么？** 用一句动词短语描述主任务，如“把选区转换为任务”“在日历中重排笔记”“导出当前查询”。
2. **谁拥有状态？** 区分 vault 文件、frontmatter、插件 data、可重建索引、内存 UI 状态和外部服务状态；同一事实只设一个权威来源。
3. **会产生什么副作用？** 文件写入、重命名/删除、网络请求、外部发布、媒体播放、启动进程、剪贴板分别列出；权限和确认与风险匹配。
4. **如何中断和恢复？** 定义重复触发、取消、重载、断网、部分成功、旧请求迟到、插件卸载和版本升级后的行为。
5. **什么证据才算完成？** 将纯函数、宿主交互、真实外部服务、设备兼容和发布状态分层，不用低层证据替代高层结果。

## 通用状态与生命周期

- 让状态转换可列举：idle/loading/ready/empty/error/disabled 等按产品裁剪。UI 从状态派生，不能由多个事件各自改一半 DOM 造成矛盾。
- `onload` 只注册必要能力，昂贵工作按需或布局就绪后执行。注册用宿主管理接口，组件、observer、timer、快捷键、网络/媒体任务和对象 URL 在视图关闭或 `onunload` 清理。
- 多 leaf、多窗口和重复打开是正常状态。不要把 view、DOM、Editor 或 activeFile 当永远唯一；动作开始时捕获目标，提交前重新校验。
- 初始化、刷新和重渲染必须幂等。重复注册命令/扩展、重复监听、重复写默认数据和重建同一菜单都属于生命周期缺陷。

## 数据与失败模型

- 用户数据、插件配置、可重建缓存和远端镜像分开。加载失败不能一律回落默认值并覆盖原数据；迁移成功持久化后才删除旧格式。
- 写操作优先原生原子 API，并保留 Obsidian 撤销、链接更新和垃圾箱语义。跨文件或本地+远端操作不是事务时，明确部分成功和修复方式。
- 每个异步任务绑定目标和代次；取消、超时、失败、被新请求替代是不同结局。错误保留最后可用状态，并给与当前动作相关的恢复入口。
- 性能预算按插件类型选：启动时间、每次键入、索引吞吐、DOM/内存、网络次数、包体积或电量；不能只因为项目有 UI 就测 FPS，也不能只因为有文件就全库扫描。

## 选择验证矩阵

从类型表选本次真正影响的维度，再加入：浅/暗、桌面/窄屏、多窗口、重载、旧数据升级和失败恢复。小修复不要求全矩阵；新插件和架构变化必须覆盖主路径、关键数据和最高风险副作用。测试身份与证据层见 [测试与诊断](testing-troubleshooting.md)。
