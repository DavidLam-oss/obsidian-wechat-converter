# 摘录、日记与来源

## 以笔记流程为中心

文章工具栏的笔记动作在桌面分屏打开今日日记，复用已存在的旁边笔记页；不抢占阅读器。尊重日记的日期格式、目录、模板，不存在才创建。移动端无法保证同样分屏时提供明确、可返回的原生导航。

右键/选区操作按产品需求支持追加到今日日记、当前笔记。点击工具时阅读器会激活，所以“当前笔记”需要安全记录最近有效 Markdown 目标，排除已关闭/删除目标；没有目标时禁用或让用户选择，不能猜测写入文件。

活动编辑器用 Editor API 保留未保存内容和光标；后台文件用 Vault.process 原子修改。创建/追加并发要排队或以目标文件序列化，失败不得显示成功。不要在用户真实日记中跑破坏性测试。

## 内容组织

默认普通段落，标题回跳链接 + 单独 [原文] 链接。同一文章在同一目标笔记下聚合摘录，不每次重复标题/URL；重复内容不再写一份。去重身份必须包含来源、文章、目标笔记，避免把不同日记或同标题文章合并。

不要靠可见 HTML 注释或长编码标记做去重。任何隐藏标识方案都检查源码模式和 Live Preview；能从已有链接/插件索引恢复则不污染正文。迁移旧标记时只改精确可识别范围并保留用户手工编辑。

## 回跳链接

- 生成并测试真正的 obsidian:// 协议，库名包含空格、中文、&、#；逐参数编码，验证解码含义，勿假设 + 一定当空格。
- 回跳必须有稳定来源/文章身份，保存版本或足够的缓存；已保存摘录不因最近缓存淘汰失效。
- 网络来源同时提供原文 HTTPS 地址；本地电子书提供书内位置链接，不编造外部地址。链接处理器缺失、插件数据清除或文章删除时，给可恢复路径，不无限加载。
- 用点击真实日记链接验收，不能只调用内部 openArticle 后宣布协议通过。
- EPUB/PDF 锚点保留格式语义，页码、段落、文本上下文与版本信息按格式处理；重新排版/修订后不准确时提供候选，不默默跳错。

## 本地来源

通过原生文件/文件夹 Typeahead 选择剪藏目录或 Markdown 文件；选择后进入对应频道。作用域只覆盖用户配置，未配置不全库扫描。移除来源不删文件。原生 Markdown 渲染支持本地图片、内部链接；使用 metadata 的 title/source/url 等字段需回退。

RSS/Atom、博客目录、OPML 是可选适配器，不是所有插件必须实现。精选重质量和全文可读，社区目录与编辑精选分开；不要写死目录数量。用户明确拒绝的 Wechat2RSS 分类不重加，也不自动化操作微信。

## 内容语义与路径

播客摘要、源逐字稿、AI 改写是不同内容状态；缺全文时不能拿简介冒充原文或触发基于全文的加工。展示 views、时长、相对日期时沿用数据真实语义，不推算伪精确时间或把页面浏览数当播放量。Markdown/PDF 导出应使用用户选择/配置的目标目录，写回路径可点击；跨平台对包含空格、中文与特殊字符的文件真实打开验证。
