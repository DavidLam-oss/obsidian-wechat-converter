# 近期经验与适用边界

来源：用户连续产品纠正、RSS 实际代码/截图/发布记录、Book Reader/Seed 的源定位与独立开发经验。仅提炼行为，不复制私人日记、库路径或聊天原文。

| 观察/偏好 | 可复用决策 | 边界 |
| --- | --- | --- |
| 搜索、频道、元信息占阅读空间 | 导航按需、列表可调宽、正文优先 | 非阅读类插件不强制双栏 |
| 默认 hover 很打扰 | 默认关闭不必要 tooltip，保留辅助技术 | 旧 RSS 个别图标例外不覆盖最近纠正 |
| 设置要点完成、滚动后不见 | 前后台共享设置、即时保存、锚定面板 | 危险/昂贵操作仍需明确反馈 |
| 每次选 tab 多一条导航 | 宿主节点复用，重渲染必须幂等 | DOM根因要本项目核实 |
| 加载时上下篇快捷键失灵 | UI选择立即更新，过期响应不能覆盖 | 不劫持编辑器输入 |
| 返回频道忘记位置 | 每频道恢复文章、列表、正文和筛选 | 同频道点击只关闭 |
| 笔记功能直接抢走页面 | 日记旁开，摘录聚合、保留双链接 | 移动布局按宿主能力降级 |
| 内部注释显示给用户 | 元数据不污染阅读/笔记 | 检查 Live Preview 与源码 |
| 链接/拖拽“代码对却无效” | 真实点击协议、实际图片嵌入验收 | 内部函数与合成事件不足以证明 |
| 字体包导致产物太大、扫描慢 | 单个离线 WOFF2 子集 + 设备字体 | 5 MB 是当前预算非永久政策 |
| GitHub发了市场却搜不到 | 发布状态分层，目录后台与公开页回读 | 历史记忆不能覆盖实时证据 |
| 客户端显示新版却无法安装 | 先公开同版本 Release 并匿名验证精确资产 URL，再让默认分支 manifest 暴露新版 | 已登录 CLI 能读 Draft，不能代表普通安装器可读 |
| README/截图仍留旧能力 | 随release更新真实产品介绍 | 商店缓存可能晚于代码 |
| fork 改名是否能提交 | 保留来源与授权证据 | 不把重命名当独立原创 |
| 规模数据导致 DOM/内存/输入延迟放大 | 分离数据模型、索引、视口渲染与可回收资源 | PDF 只是发现该模式的一个案例 |
| 自动测试通过但宿主环境或主路径没运行 | 证据绑定 checkout/vault/版本/fixture，并按插件类型选路径 | 错误环境和相邻功能不能互证 |
| 外部能力可列出但没有最终结果 | 区分发现、授权、调用、结果和恢复 | AI/Skill 只是外部集成的一种 |
| 多个插件共享同一类数据或服务 | 用最小版本化协议明确所有权，不复制认证和副作用 | 跨仓库实现需要独立授权 |
| 旧异步任务干扰用户当前选择 | 去重、代次隔离、有界恢复并保留当前意图 | 电台跳台只是该竞态的一个案例 |
| 接口成功但返回内容不符合任务 | 抽查结果语义和真实用户动作 | HTTP 200/非空列表不等于质量通过 |

近期规则的优先级：用户最后一次明确修改覆盖同一设置的旧偏好（例如 RSS popup 最初关闭、后来要求默认开启）；跨项目默认只推广重复偏好和安全不变量，精选作者、字号数值、源数量留作 RSS 适配器。


## 2026-09-08—09 的增量

本轮用户直接确认的优先级：降低操作和认知负担；选文自动切换已打开 AI 的上下文；内置快捷问题且非中文增加翻译；同类划线统一；笔记能回到原文；背景接管阅读画布但工具栏区分；设置对齐、有效、按任务组织；默认关闭不必要 tooltip。

落实位置：[通用 UI 与设置](product-ux.md)、[阅读闭环与验收](reader-workflows.md)。不把“不要自动发送”误读为“不要自动更新上下文”，不把“简化设置”实现成隐藏缺密钥/未登录错误，也不把“改阅读区”扩大为全局修改 Obsidian。

这些是用户选择和待持续验证的规则，不是对最近所有问题均已修复的声明。旧记忆出现“选文自动打开 AI”或“快捷问题可自定义”时，以这里和当前请求为准。

## 2026-09-08—15 的跨项目增量

Reader、RSS、Seed 与 Radio 是发现问题模式的案例，不是技能默认产品模板。通用化后，规则适用于命令、编辑器、视图、索引、导入导出、网络同步、媒体和 AI 插件：先识别状态所有者与副作用，再选择性能、异步、能力和验证策略。详细来源与抽象过程见 `reports/retrospective-2026-09-08-to-15.md`。

## 2026-09-16—27 跨会话增量

见 [复盘与来源矩阵](../reports/retrospective-2026-09-16-to-27.md) 和 [设置 GUI](settings-gui.md)。本轮新增重点：作用域内黑灰组件、统一留白和 logo 基线、类型平铺与复杂配置弹窗、任务式设置分组、最新 tooltip 例外；跨项目保留真实安装边界、个人订阅隔离、跨日迁移恢复、媒体结果持久化、隐藏容器初始化和分阶段性能证据。项目具体 tab 数、默认三条、指定来源名单与单次延时数字不提升为通用硬规则。
