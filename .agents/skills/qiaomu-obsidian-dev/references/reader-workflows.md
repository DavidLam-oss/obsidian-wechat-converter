# 学习型阅读器：最近纠正形成的默认交互

适用于 Book Reader 类产品；来源为 2026-09-08—09 用户连续纠正。不是所有 Obsidian 插件都要实现书库、AI 或预装图书。通用设置和宿主边界见 [阅读与设置](product-ux.md)。

## 书库服务于学习

- 首屏帮助继续阅读、找到有划线的书、打开阅读笔记。封面用来识别书籍，避免巨大封面挤掉学习信息；缺封面要有可辨识回退。
- 卡片上的进度、划线数、笔记入口必须来自真实数据且可操作。状态筛选保留；无明确任务价值的加减缩放控件移除，以自适应布局处理空间。
- 借鉴 Apple Books 的书籍识别、Readwise 的摘录回顾、Goodreads 的阅读状态等机制时，先验证现有设计，不自动增加社交、评分或商店。
- 用户要求非空首次体验时，可提供少量本地公版示例。逐本核对版本/译者、来源、再分发条件和实际体积；无插图也不等于无版权或必然小文件。只导入一次，删除后不擅自补回；不覆盖用户书库，不静默下载大文件。

## 选区动作稳定且一致

- popup 与右键复用同一套动作及状态：划线、批注、问 AI、复制。位置链接、引用格式和低频操作收进更多；翻译也可由非中文上下文快捷问题触达。
- 选中只展示动作，不等于保存或发送。工具定位不遮挡选文，点击控件、展开菜单和打开编辑器时保留原选区；点空白关闭，不误翻页。
- 划线主按钮使用记住的颜色；旁边箭头打开锚定 dropdown，直接选色。已有划线改色更新原记录，避免重复新增。
- 黄/绿/粉使用统一的填充风格和语义 token，正文、列表、笔记一致；粉色不能变成红框。定位时的临时提示与持久划线分开。
- 批注就地多行编辑，保留草稿，Cmd/Ctrl+Enter 保存；中文输入法确认不触发提交。已有划线可编辑、改色、删除，取消不会误保存。

## 划线与笔记的完整回路

- 划线列表的每一项都应跳到这本书的对应位置；摘录右侧提供简短位置链接，点击后打开正确书籍并定位划线。
- 保存稳定书籍身份、格式适配锚点和足够的文本上下文；旧锚点失效时有有限范围的文本回退或候选，不能静默跳错或无限全文扫描。
- 验收从真实列表/Markdown 链接开始，覆盖切章、字号改变、重载、书籍未打开及旧划线。内部函数返回成功不算完整通过。
- 保留用户笔记中的手工编辑；新链接迁移只触及可明确识别的插件内容。通用写入与协议规则见 [摘录与来源](capture-navigation.md)。

## AI 跟随语境，发送由用户决定

| 发生的动作 | 默认行为 |
| --- | --- |
| AI 已打开，重新选文 | 自动更新待提问上下文，展示简短选文摘要及所属书籍/位置 |
| AI 未打开，仅选文 | 显示选文动作；不抢占阅读区，不自动提问 |
| 点击问 AI | 打开/聚焦助读并带入选区；没有明确提问动作不发送 |
| 点击内置快捷问题 | 对当前上下文直接发送该问题 |
| 生成期间重新选文 | 当前请求使用发送时的快照；新选区留给下一次提问，界面明确区分 |

快捷问题保持内置，不要求用户编辑提示词；非中文选文增加“翻译成中文”。快捷问题放在输入框上方，上下文可见且可移除，不堆大段说明。保留问题草稿和按书籍组织的对话，不把选中另一段当成清空历史。

AI 表面优先中性灰阶、轻边框与清晰文字层级，避免大片浅粉/紫底。停止生成是普通过程控制，用克制的方形停止图标，不使用危险删除式红色强调。保留中断后的内容、复制和写入笔记，错误有可恢复入口。

## 阅读器回归按改动选择

- 分页：真实 EPUB/MOBI，单列/双列、跨章、连续前后翻页、改变字号和宽度、打开旁边笔记/AI 后重排、重开后恢复位置。声明支持 PDF 时补相应验证，不用一种格式替代另一种。
- 卡死/疑似泄漏：先分别查布局循环、长任务、导航队列、iframe/对象 URL/监听释放；测多轮打开翻页关闭的趋势与存活资源。一次内存升高不能直接称泄漏，按钮恢复可点也不能证明泄漏已修复。
- 视觉：阅读背景覆盖整块画布；浅色主题上下栏为白色或自然中性表面并贴合边缘，暗色适配宿主；没有重复标题、右侧意外留白、越界弹层或被压缩的笔记区。
- 不为每次改色跑全量格式矩阵；按本次影响补检查。具体证据分层见 [测试与诊断](testing-troubleshooting.md)。
