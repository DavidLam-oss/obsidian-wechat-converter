# 产品流程说明

## 核心流程

用户在 Obsidian 中打开转换器面板后，插件读取当前 Markdown 笔记，经过渲染管线生成接近发布端效果的预览。用户可以在预览中检查标题、正文、代码块、公式、图片、表格和 callout，然后选择复制富 HTML 到微信公众号编辑器、同步到微信草稿箱、同步到飞书云文档，或交给浏览器发布助手保存到其他内容平台草稿。

## 用户路径

- 打开 Obsidian 笔记，通过 ribbon 或命令面板进入转换器。
- 在转换器面板查看实时预览，并按需要调整主题、字号、样式、封面、摘要和发布账号。
- 选择“复制到公众号”时，插件输出微信编辑器可粘贴的富 HTML。
- 选择“同步到微信草稿箱”时，插件处理本地图片、公式图、封面和摘要，然后调用微信 API 创建或更新草稿。
- 选择“同步到飞书云文档”时，插件把当前笔记转换为飞书文档结构，并创建、覆盖或重绑目标文档。
- 选择“其他平台”时，插件通过本地浏览器扩展桥接，把文章和封面发送到知乎、掘金、CSDN、小红书等平台草稿流程。

## 状态变化

- 预览状态随当前文件、编辑内容、主题设置和渲染依赖加载状态变化。
- 微信同步状态覆盖账号选择、token 刷新、素材上传、草稿创建/更新、失败重试、配额保护和可选清理目录。
- 飞书同步状态覆盖应用配置、目标文件夹、文档绑定、图片上传、API 调用统计和错误恢复。
- 多平台状态覆盖浏览器插件连接、平台选择、任务投递、草稿链接和失败原因。
- 异常恢复以用户可读 Notice、弹窗状态和单平台重试为主；源 Markdown 不会因渲染或中文标点规范化被改写。

## 维护规则

- 每次用户流程、页面跳转、任务状态或异常处理发生变化后，必须检查并更新本文件。
