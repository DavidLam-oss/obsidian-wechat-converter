# 卡片封面图源工作台与 Unsplash 配置方案 — 详细设计规划

> 状态：规划就绪（待阶段实现）
> 适用模块：小红书卡片排版模式、封面配图系统、插件设置面板
> 核心目标：解决 320px 侧边栏选图局促与视觉候选受限问题；补齐 Unsplash 官方搜索 Key 配置与顺滑指引；构建专业高效的独立选图工作台（Media Picker Modal）。

---

## 1. 背景与问题诊断

### 1.1 现状与痛点

1. **Unsplash 官方 Key 存在读取但缺失配置入口**：
   - 源码 `views/converter/card-cover-settings.js` 中已预留 `view.plugin?.settings?.unsplashAccessKey` 读取逻辑；
   - 但在插件全局设置页面（`views/settings/`）中完全缺失输入项，导致用户即使有 Key 也无处填写；
   - 用户尝试按关键词搜索时，直接弹出提示未配置并降级到随机摄影，体验割裂。

2. **Picsum 服务无法支持关键词语义检索**：
   - Lorem Picsum（`picsum.photos`）底层机制是基于图库静态图片 ID 或随机 Seed 进行拉取，**完全不具备图像语义理解与关键词检索能力**；
   - 早期历史上的免鉴权接口（`source.unsplash.com`）已于 2022 年底被官方永久下线；
   - 因此，要实现“输入关键词搜索对应主题摄影大片”，必须接入 Unsplash 官方 API。

3. **320px 侧边栏与“视觉密集型选图”之间的空间矛盾**：
   - 侧边栏空间局促（宽度约 300px - 340px），非常适合承载**文字微调、版式切换、开关切换等参数控制**；
   - 但选图属于**视觉密集型决策**：用户需要大网格多列对比照片的色彩、构图、光影，而在侧边栏里只能做“输入词 -> 抓 1 张单图 -> 盲盒式替换”，无法浏览候选图；
   - 笔记内的多张插图也只能塞在狭窄的下拉菜单里猜文件名，无法直观预览大缩略图。

### 1.2 架构演进原则：分层职责（侧栏微调 + 弹窗挑图）

参考 Notion、Canva、Figma 等现代生产力工具的成熟实践：
- **侧边栏（保留为控制台）**：负责高频的版式切换（纯文字/融入主题/底图遮罩/全幅海报）、文案编辑（标题/作者/日期/摘要）、当前配图状态展示，改动后保持卡片毫秒级重排与所见即所得（WYSIWYG）；
- **选图工作台（独立轻量弹窗 Media Picker Modal）**：负责低频但需要大画布的“挑图”，包括 Unsplash 候选大网格浏览、笔记插图大图平铺、AI 生图风格对比等，选定图片后自动回填侧栏并自闭合。

## 2. 设计边界与硬性约束

### 2.1 代码行数治理规范（铁律）

项目经过多次重构，确立了严格的代码行数与职责边界规范：
- **单文件软上限：800 行**：
  任何文件一旦接近或达到 800 行，必须按照单一职责原则拆分出子模块（例如卡片预览拆出 `card-page-selection.js`，封面拆出 `card-cover-settings.js`）；
- **单文件硬上限：1500 行**：
  红线约束，严禁任何生产代码文件突破 1500 行；
- **本方案各模块文件行数预分配**：
  - 弹窗宿主与生命周期：控制在 250 - 350 行；
  - 各 Tab 渲染器拆分子文件，单文件控制在 200 - 350 行；
  - 严禁将全部弹窗逻辑堆叠进现有 `card-cover-settings.js`（该文件当前已 617 行，必须将挑图弹窗独立于新模块）。

### 2.2 所见即所得（WYSIWYG）原则

- 封面版式、文本输入、封面开关等高频调整必须保留在侧边栏，任何编辑实时触发 `renderCardPreview()`，绝不要求用户每次改文案都要打开弹窗；
- Media Picker 弹窗仅在需要“选择/更换封面图片”时唤起；在弹窗内选中任意图片后，立即写入会话 `coverImage`，更新侧边栏回显，触发卡片重排，并自动关闭弹窗。

### 2.3 视觉与代码规范

- **严禁使用任何 emoji**：界面文案、注释、测试用例、提交日志及文档全流程无 emoji；
- **无 innerHTML**：严格遵守 Obsidian 官方上架审查规范，所有 DOM 创建通过 Obsidian 原生 API（`createEl`, `createDiv`, `createSpan` 等）与 `dom-utils.js`；
- **视觉风格一致性**：复用项目现有的 Apple 设计语言（灰轨道胶囊、扁平卡片、微质感边框、层级清晰的字体与间距）。

## 3. 阶段一：Unsplash Key 全局配置与平滑指引

### 3.1 目标

1. 在插件全局设置面板中提供清晰的「Unsplash Access Key」配置项与指引；
2. 在侧边栏搜索时，对未配置 Key 的状态做平滑降级与快捷引导，消除生硬报错感。

### 3.2 详细设计与实现细节

#### 1. 全局设置项（views/settings/ai-tab.js）
- **归属位置**：在「AI 服务」Tab 内新增独立分节「图源与搜索服务」（或「摄影图源服务」）；
- **配置表单项**：
  - **标题**：`Unsplash 摄影图库 Access Key`
  - **输入框**：带密码掩码与一键明文切换的文本框（placeholder: `例如: d8f3a9e...`），回车或失焦即自动保存到 `plugin.settings.unsplashAccessKey`；
  - **操作按钮**：
    - `测试连接`：调用 Unsplash 的 `/photos/random?count=1` 轻量接口验证 Key 有效性，成功提示“连接成功”，失败显示具体错误码（如 401 凭证失效）；
    - `清空`：一键清除已存 Key；
  - **帮助指引（详细且易懂）**：
    - 提供直达官方开发者平台的跳转链接：`https://unsplash.com/developers`；
    - 说明文字：“1. 注册/登录 Unsplash 账号；2. 点击 Your Apps 创建新应用（免费个人版）；3. 复制生成的 Access Key 粘贴至此。免费版提供 50 次/小时搜图额度，足够日常写作配图使用。”

#### 2. 设置持久化与归一化（services/plugin-settings.js）
- `DEFAULT_SETTINGS` 显式增加 `unsplashAccessKey: ""`；
- 设置持久化与迁移函数中保留该字段的字符串清洗（去除首尾空格）。

#### 3. 侧边栏快捷交互优化（views/converter/card-cover-settings.js）
- 当检测到 `!unsplashKey` 时：
  - 点击“搜索”不再抛出刺眼的 Notice 警告，而是弹出确认/气泡提示：
    “未配置 Unsplash Access Key，无法执行精准关键词搜索。您可以先使用 Picsum 获取精选随机摄影图，或前往设置配置 Key。”
  - 提供两个直观按钮选项：`[获取随机图]` 与 `[前往设置]`（点击直接调用 `view.plugin.openSettings()` 并定位到对应 Tab）。

### 3.3 涉及文件与预估行数
- `services/plugin-settings.js`：增加 ~5 行配置项定义；
- `views/settings/ai-tab.js`：增加 ~60 行配置项 DOM 构建与连接测试（原 710 行，增加后约 770 行，在 800 行软线内）；
- `views/converter/card-cover-settings.js`：更新搜索未配置 Key 时的降级引导（~20 行）。

## 4. 阶段二：封面独立选图工作台（Media Picker Modal）

### 4.1 总体架构与数据流

```
[ 侧边栏封面面板 (card-cover-settings.js) ]
       │
       │ 点击「+ 选择配图」或「更换配图」
       ▼
[ Media Picker 独立弹窗 (card-media-picker-modal.js) ]
 ├─ 顶部 Tab 1: Unsplash 摄影搜索 (card-media-picker-unsplash.js)
 ├─ 顶部 Tab 2: 笔记插图与本地 (card-media-picker-note.js)
 └─ 顶部 Tab 3: AI 灵感生图 (card-media-picker-ai.js)
       │
       │ 点击选中任意一张图片
       ▼
 写入 session.applyCoverFields({ coverImage, coverImageSource })
 关闭弹窗 -> 侧边栏缩略图更新 -> 卡片实时重排渲染
```

### 4.2 侧边栏职责精简（保持极度轻巧）

在引入挑图弹窗后，侧边栏封面区域大幅精简：
- **保留字段**：
  - 封面页开关（开启/关闭）；
  - 版式选择（纯文字 / 主题自适应 / 底图遮罩 / 纯图海报）；
  - 封面文案编辑（标题 / 作者 / 日期 / 摘要 / 重置文案）；
- **配图操作简化**：
  - **未配图时**：展示一枚醒目的中号操作按钮 `+ 选择封面配图`（点击直接呼出 Media Picker 弹窗）；
  - **已配图时**：展示配图卡片（大圆角缩略图 + 尺寸信息 + 图源标签），右侧附带两个轻量操作：`更换`（唤起弹窗）与 `移除`（清除配图并切回纯文字）。
- **收益**：侧边栏不再堆砌复杂的关键词搜索栏、多行小按钮和展开细节，代码量从 617 行降低至 400 行左右，视觉层级极为整洁。

### 4.3 Media Picker Modal 弹窗详细设计

#### 1. 弹窗容器规范（card-media-picker-modal.js）
- 继承 Obsidian 原生 `Modal` 类；
- 弹窗尺寸：宽 680px - 720px，最大高 80vh（适配各类桌面与平板视口）；
- 顶部导航：采用 Apple 风格的分段胶囊 Tab 控件（`Unsplash 摄影` / `笔记与本地` / `AI 生图`）；
- 具备记忆能力：打开时自动记忆上次停留在哪个 Tab。

#### 2. Tab 1 · Unsplash 摄影搜索（card-media-picker-unsplash.js）
- **搜索区域**：
  - 顶部常驻大尺寸输入框（带搜索图标与清空按钮）；
  - 快捷标签推荐（横向可滚动的胶囊芯片）：`极简`、`建筑`、`科技`、`自然`、`办公`、`生活`、`质感`、`暗黑`，点击即刻填入并发起搜索；
- **多列候选网格**：
  - 3 列自适应摄影大图网格（Aspect Ratio 匹配当前卡片比例，如 3:4 或 1:1）；
  - 图片悬浮动效：微放大 + 阴影浮起 + 选中高亮边框；
  - 底部附带半透明渐变层，展示摄影师名称与 Unsplash 来源标（符合官方 API 使用规范）；
- **交互与选定**：
  - 单击网格中的任意图片 -> 触发高清 Base64 转换与拉取 -> 写入会话 -> 关闭弹窗；
  - 支持底部“加载更多”按钮或滚动分页。

#### 3. Tab 2 · 笔记插图与本地上传（card-media-picker-note.js）
- **笔记已插入图片区**：
  - 自动从当前活跃笔记中提取全部插图；
  - 采用 3 列大缩略图平铺展示，下方展示图片标题与尺寸信息；
  - 点击任意一张笔记插图即刻应用；
- **本地图片上传区**：
  - 顶部或底部提供大面积虚线拖拽区域（“拖拽本地图片到此处，或点击浏览文件”）；
  - 支持常用格式（PNG, JPG, WebP, SVG）；
  - 选定本地文件后自动转 Base64 并应用。

#### 4. Tab 3 · AI 灵感生图（card-media-picker-ai.js）
- **预设风格可视化大卡片**：
  - 不再使用生硬的文字下拉菜单；
  - 采用 2 列风格画廊卡片（3D 粘土、扁平矢量、写实摄影、赛博朋克等），每张卡片展示该风格的真实样本图与简短说明；
- **Prompt 辅助与生成**：
  - 结合当前笔记标题与摘要自动生成 Prompt；
  - 点击“开始生成”，卡片区域展示微质感骨架屏呼吸动画；
  - 生成完毕后呈现大图预览，用户可点击“采用此图”或“重新生成”。

### 4.4 模块拆分与行数控制规划

为彻底杜绝大文件膨胀，阶段二严禁堆单文件，必须采用清晰解耦的模块化结构：

| 文件路径 | 职责定位 | 预估行数 |
| :--- | :--- | :--- |
| `views/converter/card-media-picker-modal.js` | 弹窗 Shell、Tab 切换状态机、结果回调桥接 | ~260 行 |
| `views/converter/card-media-picker-unsplash.js` | Unsplash 关键词搜索、标签推荐、网格候选渲染 | ~320 行 |
| `views/converter/card-media-picker-note.js` | 笔记插图提取平铺、本地拖拽上传、图片读取转换 | ~220 行 |
| `views/converter/card-media-picker-ai.js` | AI 风格大卡片展示、Prompt 解析、异步生图预览 | ~280 行 |
| `styles/card-media-picker.css` | 弹窗容器、分段导航、候选网格、加载动效专属样式 | ~350 行 |

所有新建文件均稳稳控制在 **300 行上下**，远低于 800 行软线，彻底避免越线风险。

## 5. 验收标准与测试矩阵

### 5.1 阶段一验收标准
1. 打开 Obsidian 插件设置 -> 「AI 服务」Tab，能看到「Unsplash Access Key」输入卡片；
2. 输入有效 Key 点击“测试连接”，能够成功收到 Unsplash 校验成功的提示；
3. 未配置 Key 时，侧边栏搜索提供友好的随机图回退与“前往设置”跳转按钮；
4. 配置 Key 后，在侧边栏输入关键词能正确按词获取对应的 Unsplash 摄影大片并应用到封面；
5. 新增单元测试覆盖：`unsplashAccessKey` 设置存取、空 Key 降级处理、Unsplash 搜索逻辑。

### 5.2 阶段二验收标准
1. 点击侧边栏「+ 选择配图」或「更换配图」能够唤起宽阔居中的 Media Picker 弹窗；
2. 弹窗在 320px 侧边栏以外展开，提供 680px 以上的宽裕挑选视口；
3. Unsplash Tab 下支持关键词搜索、标签点选与 3 列摄影候选网格展示；
4. 笔记插图 Tab 下真实渲染当前笔记所有插图的缩略图，并支持本地图片拖拽上传；
5. 选中任意候选图片后，弹窗平滑关闭，侧边栏缩略图同步更新，卡片预览实时重排呈现；
6. 全部代码遵守 800 行软线规范，Vitest 测试套件全绿，`npm run scan:guard` 零警告通过。
