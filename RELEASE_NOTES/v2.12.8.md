## 更新内容

### ✨ 卡片导出弹窗 UI/UX 工业级重构（对齐 Apple / Figma 体验）
- **导出中极致纯净与性能保证**：彻底移除导出中下方的冗余逐页列表与滚动条，仅保留顶部状态文案、线性进度条与取消按钮。从物理上避免了在后台密集执行 Retina PNG / Canvas 2D 高负荷光栅化时，用户拖拽滚动条导致的掉帧卡顿。
- **状态原地增量修补（In-place Patching）**：使用细粒度增量更新替代全量 DOM 销毁重绘，导出期间主线程 DOM 操作降为极小常数级，将 CPU 算力 100% 留给图片导出。
- **全成功态无缝衔接**：全部导出成功后，进度条平滑替换为「输出目录卡片」与「打开所在文件夹」大按钮；不展示无信息的 100% 成功单页列表，弹窗高度保持一致稳定，消除了“中途没有、后来突兀冒出”的割裂感。
- **异常态精准诊断展开**：仅在存在失败页（`failed > 0`）或用户取消时，自动展开失败页明细并高亮出错序号与脱敏原因，配合一键 [重试失败页] 恢复。
- **180ms 优雅淡入微动效（Fade-In）**：注入平滑的透明度与微位移动画，消除状态重绘时的硬闪烁感。

### ⚡ 卡片预览与导出图床图片处理解耦，恢复秒级极速渲染
- **预览解耦**：彻底解耦卡片模式的预览加载与导出下载链路，卡片预览直接原生渲染图床/远程图片，无需等待本地拉取内联，恢复卡片模式切换与预览的秒级丝滑体验。
- **导出图床稳健性增强**：导出时增加内存图片缓存、网络请求失败重试与图片损坏跳过兜底，保证多图批量导出不中断。

### 🐛 卡片模式切换稳定性与跨平台导出清理修复
- **切换竞态与生命周期重置**：视图打开/关闭跨会话重置预览状态，同步侧栏模式 UI 与设置面板；消除 Landing Gate 与 onResize 竞态条件，修复跨窗口 `HTMLElement` 判定与孤立占位清理。
- **跨平台导出清理增强**：修复多平台发布导出时，在文章模式下安全清理 `.owc-engagement-card` 与 `figure figcaption`，同时完全不影响微信公众号的预览、复制与草稿箱同步。
- **样式安全规范化**：优化卡片加载转轮样式，用纯 CSS 边框圆环替代 `-webkit-mask` 规则，消除静态扫描风险。
