## 更新内容

### 🚀 重大更新：图片卡片导出系统

- **全新「卡片模式」**：在文章排版、微信贴图之外新增第三种预览模式，把笔记渲染成适合小红书、公众号次条等场景的图片卡片，支持一键批量导出 PNG。
- **多版式与多主题**：内置文章卡、金句卡等多种版式，新增 `paper-notes`（纸感）与 `dark-take`（深色）主题；解锁 3:5、9:16 等更多画面比例，统一缩放取整规则。
- **智能分页排版**：分页引擎支持孤立行规则与原子单元（图片、代码块）保护，超大单元无法单页容纳时会给出明确诊断而不是静默失败。
- **封面系统**：
  - 支持 Frontmatter 指定封面、正文首图自动采用、本地上传、Unsplash 摄影图库与 AI 生成五类来源。
  - 封面按主题自动分派为「贴边 / 画框 / 整页」三种处理，并把封面高度钉死为恰好一页。
  - 新增「融进版面」版式，封面与正文排版自然衔接。
- **AI 封面生图**：
  - 新增独立 AI 服务设置 Tab，支持通用双模生图与按能力探测的连接测试。
  - 生图工作流支持主题输入、AI 提炼视觉核心观点、实时进度显示与历史缩略图。
  - 新增 Unsplash Key 配置与独立选图工作台。
- **导出能力**：支持按页自选导出（全部 / 选定）、复制单张卡片到剪贴板、导出弹窗集成「在访达中显示」；批量导出以清单（manifest）记录结果，失败页可重试，异常中断可恢复。
- **笔记级隔离**：全局卡片默认值与每篇笔记的独立会话分离，切换笔记时封面、版式等编辑状态互不污染。

### ✨ 设置面板与多平台

- **视觉设计语言统一**：微信、飞书、AI、多平台各 Tab 全量接入统一 Section Header 布局，界面风格一致。
- **平台照片墙与勾选矩阵融合**：多平台 Tab 置顶展示支持平台矩阵，未开启时为全览、开启后为交互勾选控制。
- **平台图标全离线**：27 个主流平台高清图标内嵌为本地 Base64，彻底消除外部网络请求与滚动闪烁。
- **浏览器配对**：待配对请求新增「忽略」按钮，配对注册表支持主动清理待处理客户端。

### 🐛 问题修复

- **修复切换笔记时异步结果串台**：AI 生图、Unsplash 选图、AI 提炼观点在笔记切换后会把结果写回原笔记会话，不再污染当前笔记，也不再误报「已切换笔记」。
- **修复「默认封面版式」不生效**：全局默认封面版式在选择「自适应融入主题」等选项后，重启 Obsidian 不再被静默改回默认值。
- **修复卡片导出中断后卡死**：结果记录写入失败时会正确复位运行状态，导出弹窗提供「重试记录清单并继续」与「取消导出」两条出路。
- **修复列表内嵌块级元素错乱**：列表项中的代码块、表格、引用、`div`、`hr` 等块级元素会被解构为同级兄弟，避免转换为微信 HTML 时 `<p>` 标签提前闭合。
- 支持 `font` 标签自动归一化为微信行内样式 `span`。

### ✨ 体验优化

- **预览诊断**：模式渲染失败或超时时，预览区直接显示可复制的诊断信息，不再「选了模式没反应」。
- **落地页门控**：插件侧边栏保留落地页直到用户真正打开一篇笔记，避免抢焦点事件导致的空渲染。
- **设置持久化稳定性**：设置保存时的原地同步会保留数组元素对象引用（按 `id` 或 `name` / `key` / `title` 等语义键匹配），UI 组件持有的引用在重新排序或增删后依然正确。

### 🧪 测试保障

- 全量 147 个测试套件、1885 个测试用例通过。
- 新增卡片分页、导出清单恢复、异步会话隔离、设置归一化、列表块级元素解构等回归测试。
- **质量门禁强化**：ESLint 接入上游 `eslint-plugin-obsidianmd` recommended 配置（升级至 0.4.2），并新增 `no-console-disable`、`no-this-alias`、`no-unbalanced-eslint-disable`、`no-css-has` 四条自定义扫描规则与 `runScan` 集成测试，把社区审核的高频问题挡在提交之前。
