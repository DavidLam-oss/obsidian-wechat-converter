## 更新内容

### 🚀 卡片主题库：6 套经典 + 11 套情绪调色盘
- **11 套小红书爆款情绪调色盘**：新增 warm / cyber / ocean / forest / elegant / sakura / metal / starry / minimal-white / yueling / dark-night 共 11 套色盘（Note to RED 来源，MIT 协议适配），只保留高质感底色与纯粹排版 Token，不带任何头像 / UID 挂件。与原有 6 套经典主题并列，卡片主题总数达到 **17 套**。
- **主题面板分组收纳**：默认展示 2 行 × 3 列经典主题，11 套调色盘折叠收纳、一键展开；当前正在使用的调色盘会自动保持展开，不用每次重新翻。

### 🤖 AI 一步一步生成你的专属主题
- **一句话生成主题**：在侧栏输入设计诉求（并可从灵感 pill 里挑现成说法），由已配置的 AI 模型产出合法的 CustomThemeToken，经过校验与规范化后直接套用到预览，无需手写 JSON。
- **可持续微调**：生成结果不满意可以继续追加要求做迭代，配合内置的提示调优建议，越改越接近想要的样子。
- **锁定主题色**：勾选后 AI 只调排版不动主色，避免每次生成都把品牌色换掉。
- **生成按钮与弹窗统一视觉**：AI 生成入口改用原生 mod-cta 样式，弹窗内文案去掉表情噪音。

### 🎨 标题样式体系与 Token Schema 扩展
- **二级标题 4 套分节风格**：经典极简 default（沿用主题原生左边框/底色块）、大数字序号 serial-number（34px 双位数序号下沉对齐 + 底部细线）、胶囊徽标 badge（圆角序号标签 + 渐变分割线）、留白禅意 zen（居中 PART 字距 + 宋体大标题 + 42px 细分割线）。
- **切换器搬进侧栏设置面板**：改风格当场 WYSIWYG 刷新，不必再反复开关设置窗口；「默认」按钮文案改为「跟随主题」，含义更直白。
- **Token Schema 四项扩展**：h3Style（bottom-line / left-border / classic / simple）、blockquote.style（soft / center / paper / minimal）、typography.strongStyle（color / neutral / highlight）、colors.canvas（整篇底色）。AI 提示词、字段校验、normalize、adapter 与渲染引擎五层同步扩到位，AI 生成的自定义主题不会因为字段没被识别而悄悄回落。
- **标题主色跟随主题设置**：修正标题主色只认主题、不认用户设置的问题。

### ✨ 其它体验提升
- **封面配图可拖着调**：预览里按住封面图拖拽平移、滚轮缩放（60fps 手势响应），放手自动记住位置与缩放，不用反复重传图。
- **文末互动三连卡**：点赞 / 在看 / 转发三连卡，全量继承当前主题色，纯内联样式 + 微矢量 SVG（微信后台会剥离外部 CSS，所以必须内联），可选开启、默认关闭。
- **变量插值支持中英文别名**：`{{date}}` / `{{author}}` / `{{column}}` / `{{title}}` 均可，frontmatter 里写 `日期` / `作者` / `专栏` / `标题`、或 `publish_date` / `by` / `category` 这些别名一样认。
- **导出与草稿同步清掉占位符**：未解析的变量高亮不再跟着复制进公众号草稿。

### 🐛 问题修复
- **侧栏宽度闸门（手机框被压扁）**：侧栏一旦承载转换器面板就有 400px 下限，拖窄会被顶住，手机框与经典预览都不再被裁。把页签拖到另一侧栏、或切到别的插件面板再切回来，下限会跟着走 —— 以前会留在旧侧栏、或者锁住一条根本不在看本面板的侧栏。主编辑区分屏刻意不加限制，避免阻断「把笔记分两栏并排」这个高频操作。
- **标题前缀转义**：修复标题序号/前缀被二次转义导致的乱码，同时对前缀做 HTML 转义，堵住注入面。
- **文章模式下设置项叠层**：卡片设置区在文章模式下不再叠成多层卡片。
- **弹窗切换抖动**：各弹窗的 Tab 样式与高度统一，来回切换不再跳动。
