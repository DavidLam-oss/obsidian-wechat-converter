## 更新内容

### 🐛 问题修复
- **Mermaid 流程图箭头与样式完整性保留**：修复 Obsidian 原生 Mermaid 在 DOM 序列化安全清理时误将 `<marker>` 与 `<defs>` 内部的 `id` 剥离，导致连线箭头丢失变秃头线的问题；同时在 SVG 属性白名单中补充 `markerunits` 规范属性，确保箭头大小自适应。
- **Mermaid 百分比宽度尺寸推导修复**：优化 SVG 栅格化尺寸解析逻辑（`getSvgLogicalSize`），当检测到 SVG 采用百分比宽度（如 `width="100%"`）时，自动根据 `viewBox` 真实比例推算图表逻辑宽高，彻底避免导出的流程图被压缩变形或过小。

### ✨ 新增功能与优化
- **Excalidraw 手绘图表高保真发布到微信**：
  - 支持直接在 Markdown 笔记中粘贴由 Excalidraw 生成的矢量 SVG 图表（带有 `<!-- svg-source:excalidraw -->` 注释）；
  - 在复制或同步发布至微信的准备阶段，自动将内嵌 SVG 栅格化为高质量 PNG 图像（最大宽度 1920 智能缩放），完美绕过微信公众号编辑器对复杂 SVG 内部遮罩与字体嵌入的过滤限制；
  - 严密的代码围栏保护，确保在代码块（`~~~html` 或 ````markdown`）内部展示的 SVG 源码保持原样，不会被错误包装或转换。
