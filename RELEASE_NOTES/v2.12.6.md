## 更新内容

### 🐛 问题修复
- **设置弹窗长表单滚动与关闭按钮固定**：修复添加/编辑微信公众号账号与添加/编辑 AI Provider 弹窗在向下滚动时右上角关闭按钮 `x` 和标题被顶出视口的问题。通过引入 `.wechat-form-modal` 容器布局，外层弹窗容器禁止整体滚动，右上角关闭按钮和标题永久固定在视口顶部，将滚动条严格限制在内部表单内容区域，大幅提升长表单操作体验。
- **AI Provider 下拉选择框高度截断修复**：修复在常用服务商预设和接口协议类型的下拉框中文字被下半部分遮挡的问题，显式赋予标准行高与容器最小高度，保证在各类主题与缩放比例下均能完整呈现选项。

### ✨ 功能优化
- **微信 API 40164 IP 白名单报错人性化解析**：将底层微信接口返回的技术错误（包含 IPv6 映射、追踪 rid 等技术细节）智能解析为通俗易懂的中文配置提示，直观提取当前网络出口 IP，并引导用户前往微信公众号后台「基本配置 - IP 白名单」进行添加。
- **微信接口白名单 IP 独立诊断工具**：在微信设置面板中将公网 IP 查询正式化，抽离原先混杂在说明文案中的行内文本链接，打造为独立的 Setting 设置项。支持一键探测当前网络出口 IPv4 地址，点击后自动更新状态并复制到剪贴板，方便用户在配置公众号后台时快速粘贴。
- **AI 模型 ID 填写指引与校验优化**：清理服务商预设中陈旧且易过时的硬编码 sample 模型 ID，统一改为直观的占位符指引；在保存时增加必填检查与友好 Notice 提示，避免新用户误填或漏填。
- **界面精简**：移除 AI Provider 弹窗中 API Key 输入框后面冗余的显示/隐藏密码按钮，保持界面清爽规整。
