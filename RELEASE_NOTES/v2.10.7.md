## 更新内容

### 🚀 重大更新
- **新增“关于”设置页**：在插件设置中加入独立的“关于”标签，集中展示插件版本、项目链接、作者介绍与使用入口。
- **新增支持与赞助区**：内置微信赞赏与支付宝收款码，并加入赞助鸣谢榜，感谢每一位支持项目持续迭代的创作者。

### ✨ 功能优化
- **优化设置与品牌文案**：调整关于页标题、简介与多平台设置说明，使信息层级更清晰。
- **完善中英文项目说明**：补充赞助支持入口与说明，并修正 README 中部分列表的排版。

### 🐛 问题修复
- **兼容自定义配置目录**：关于页资源读取不再假设 Obsidian 配置目录固定为 `.obsidian`。
- **提升扫描与依赖安全性**：收窄设置页的 lint 抑制范围，并升级 XML 解析依赖以避开已知安全风险。
