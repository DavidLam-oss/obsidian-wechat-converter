## 更新内容

### 🚀 重大更新

- **AI 自定义主题升级为「元信息 + 微信安全编译 CSS」架构**：
  - 引入基于 PostCSS AST 的微信安全样式编译与内联流程，支持将标准 `::before` / `::after` 伪元素及 CSS `counter()` 自动编号渲染为实体 DOM 节点并强制内联样式，突破微信编辑器屏蔽 `<style>` 与伪元素的限制。
  - 自定义 CSS 内联过程自动保护内置互动三连卡与 Mac 代码块子树，避免通用标签规则误伤组件样式。
- **自定义主题弹窗新增实时样张预览与增量微调**：
  - 支持在主题弹窗内直接预览渲染后的真实排版样张，并可针对当前方案进行多轮对话式增量微调（Refine），同时完全向后兼容既有 JSON 主题。
- **自定义主题去除强制图标，聚焦纯 CSS 排版装饰**：
  - 停止让 AI 在标题中生成 SVG 矢量图标（同步过滤多余图标字段），转而引导使用纯 CSS 几何色条、底边线、伪元素序号与排版符号，成稿更克制耐看。

### ✨ 功能优化

- **「经典」「简约」主题回归高可读长文默认排版**：
  - 「经典」与「简约」默认参数调整为更舒展的阅读节奏（行距 `1.9`、段距 `26px`、字间距 `0.5px` 及更舒适的左右留白），「经典」标题同步切回底边线与左侧色条风格。
  - 设置面板中的手动行间距、段间距与字间距滑块依然保留完整优先级，可随时手动微调或归零覆盖默认主题配置。

### 🐛 问题修复

- 修复贴图列表移除按钮（`.sticker-image-list__remove`）存在重复 `border` 声明引发社区插件 CSS lint 警告的问题。
