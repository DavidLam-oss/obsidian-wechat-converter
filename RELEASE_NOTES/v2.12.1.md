## 更新内容

### 🐛 问题修复
- **修复直接同步草稿后手机端点击放大图片模糊问题（#86）**：针对通过 API 直接同步到微信草稿箱的图片，自动补齐微信规范所需的 `data-s="300,640"` 规格阶梯声明、`data-type` 以及 URL 查询参数 `wx_fmt` 与 `from=appmsg`，彻底解决手机微信客户端图片浏览器因缺少规格标识而降级拉伸 640px 缩略缓存导致的高清图片失真。
- **修复段落紧贴换行（软换行）在微信中行首多出一个空格的问题**：安全清洗非代码块中 `<br>` 紧跟的源码换行符 `\n`，消除微信富文本编辑器将其误解析为行首半角空格的排版瑕疵；同时严格保护代码块缩进、连续空行与中文全角缩进（`\u3000`）。
- **修复文章模式下禅意标题底部分割线样式丢失问题**：确保分节标题下方的精致分割线在同步与粘贴到微信编辑器时样式完整保留。

### ✨ 界面优化
- **优化从素材库选择封面弹窗的按钮与徽标风格**：将确认按钮从硬编码的亮蓝色调整为跟随 Obsidian 全局主题的强调色（`var(--interactive-accent)`），按钮圆角从胶囊药丸形统一为 Obsidian 标准微圆角（`var(--button-radius, 6px)`），并补齐未选中封面时的置灰禁用层级，视觉体验更加浑然一体。

### 🛠️ 基础设施与发布
- **新增 Gitee 镜像发行版自动同步与校验机制**：发版时自动同步 `main.js`、`manifest.json`、`styles.css` 至 Gitee Release，并提供 `npm run release:verify-gitee` 资产完整性校验工具，方便国内网络环境下稳定安装与更新。
