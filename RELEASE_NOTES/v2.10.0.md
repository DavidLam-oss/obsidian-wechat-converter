## 更新内容

### 🚀 微信贴图发布模式
- **笔记一键生成微信贴图草稿**：新增“贴图”排版模式，可将当前笔记整理为纯文本文案和最多 9 张配图，并同步到微信公众号草稿箱。
- **配图预览与编排**：支持从正文、frontmatter、本地上传和公众号素材库汇集图片；可拖拽排序、移除或恢复图片，并用 `[配图 N]` 标记保持文案与最终图片顺序一致。
- **贴图发布检查**：发布前展示文案字数、配图数量和上传状态；对微信贴图不支持的 Markdown 结构进行可读清理，并在图片缺失、超限或账号不匹配时给出明确提示。
- **草稿同步稳定性**：完善图片去重、公众号素材归属、逐张上传和 `newspic` 草稿创建流程，降低重复图片、错序和跨账号素材误用风险。

### 🎨 自定义 CSS 发布
- **用自己的 CSS 控制公众号排版**：新增自定义 CSS 能力，可直接在插件设置中填写 CSS，也可指定 Vault 内的 CSS 笔记作为样式来源。
- **预览、复制与同步保持一致**：自定义样式会应用到普通预览、复制到公众号和微信草稿同步结果，减少“预览正常、发布后样式丢失”的偏差。
- **适配公众号内联样式限制**：发布前自动展开选择器并内联样式；支持将 `::before`、`::after` 和 CSS 计数器等伪元素效果转换为真实内容，尽量保留公众号编辑器可接受的视觉结果。
- **安全编译与可恢复提示**：自动忽略不支持或不安全的规则，显示具体诊断；CSS 存在问题时继续使用上一次有效样式或基础主题，避免一次错误配置破坏整篇文章。
- **与 AI 编排相互独立**：普通排版可使用自定义 CSS，AI 编排保持自己的样式输出，避免两套样式叠加后互相覆盖。

### 🐛 Obsidian 1.13 设置页修复
- **恢复完整插件设置页**：修复 Obsidian 1.13.x 中进入 Wechat Converter 设置后只显示标题、无法看到公众号账号和其他配置项的问题。
- **首次配置恢复正常**：未配置公众号时会正常显示引导说明和“添加账号”入口；从发布弹窗跳转设置与直接进入插件设置使用同一套完整页面。
- **增加回归保护**：补充 Obsidian 1.13 设置生命周期、零账号提示和添加账号入口测试，防止设置页再次退化为空白。

### ⚙️ 多平台额度调整
- **免费版每日额度调整**：通过“Obsidian 发布助手”浏览器插件进行多平台发布时，免费版从每天 3 个平台额度调整为每天 1 个平台额度；超出部分会自动跳过，并在发布结果中明确说明。
- **Pro 版不受此限制**：已激活 Pro 的用户继续保持无每日平台数量限制；离线时会在有效窗口内保留已验证的 Pro 身份显示。

### ✨ 其他改进
- **排版与复制优化**：优雅主题新增行距、段距和字距微调；修复微信代码块顶部交通灯间距、可执行代码复制和引用块边框等细节问题。
- **设置与多平台稳定性**：设置页标签和 GitHub 横幅在滚动时保持可见；加强浏览器插件配对、授权状态、断线恢复、发布结果和版本策略提示。
- **公众号配置指引**：补充 AppID、AppSecret 与 IP 白名单的首次配置入口和图文指南。
